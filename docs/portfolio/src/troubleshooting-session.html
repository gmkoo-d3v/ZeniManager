로그인 문제 해결 트러블슈팅

Electron 환경에서 세션 불일치로 발생하는 로그인/무한로딩 문제를 빠르게 진단하는 방법

1. 로그인 성공

정상적인 인증
세션 토큰 발급

2. 일정 시간 대기

또는 로그아웃 후
재로그인 시도

3. 보호 API 요청

세션이 동기화
되지 않은 상태에서
데이터 요청

4. 무한 로딩

세션 누락으로 401
처리 실패로 무한 대기

5. 해결 방안

세션 재검증
401 공통 처리
보호 요청 사전 차단

DIAGNOSTIC LOGS
GET /rest/v1/user 401
auth_user = null
GET /survey_responses 404

* 404: 미배포 테이블 · 인증과 별개 원인

문제 핵심

Supabase 장애가 아니라 세션 불일치입니다. Electron 앱 내부 세션 상태와 서버 인증 상태가 맞지 않아 발생합니다.

원인

Electron 세션과 Supabase 인증 상태 불일치

증상

무한 로딩, 연결 확인 중, 로그인 직후 빈 화면

해결

세션 재검증, 401 공통 처리, 사전 차단, 8초 timeout
